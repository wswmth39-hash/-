# WSNF Smart Bot — v3.6 (محاكاة فقط + مسجّل شموع + محرك مفصول)

Userscript يحلل أسعار المنصة ويصدر إشارات وصفقات **افتراضية** فقط (Paper Trading).
**لا ينقر أي زر في المنصة، ولا يرسل أي أمر، ولا يقرأ المبلغ أو الرصيد.**

> لا يوجد دليل على أن هذا النظام مربح. على بيانات عشوائية يعطي نحو 50% كما يجب (لا تسرّب ولا عكس منهجي).
> الحكم على وجود أي أفضلية يحتاج بيانات حقيقية واختبارًا خارج العينة (المرحلتان D وE). انظر `docs/AUDIT_REPORT.md`.

## الملفات

| المسار | الوصف |
|---|---|
| `dist/wsnf.user.js` | **الملف الذي تثبّته (v3.6)** — مبني آليًا من `src/` بـ `node build.js` |
| `src/` | الكود موزّعًا على وحدات: `core/` (تحليل بحت) · `engine/` · `recorder/` · `platform/` · `ui/` — انظر `docs/ENGINE.md` |
| `backup/wsnf_v3.5.user.js` | نسخة v3.5 قبل فصل المحرك (مرجع الاختبار الذهبي) |
| `original/wsnf_v3.3.user.js` | النسخة الأصلية كما استُلمت (نسخة احتياطية، لا تُعدَّل) |
| `docs/AUDIT_REPORT.md` | تقرير الفحص (المرحلة الأولى) |
| `docs/STAGE_AB.md` | ما تغيّر في المرحلتين A وB، ولماذا، وما الذي أُجّل |
| `docs/TEST_RESULTS.md` | جدول الاختبارات قبل/بعد (يُولَّد آليًا) |
| `docs/RECORDER_DESIGN.md` | تصميم مسجّل الشموع: مصدر البيانات، حدود موثوقيته، التخزين، الحجم |
| `docs/STAGE_D.md` | تقرير المرحلة D (المسجّل) ونتائج اختباراته |
| `docs/ENGINE.md` | بنية المحرك وكيف تتواصل أجزاؤه |
| `docs/STAGE_C.md` | تقرير المرحلة C (فصل المحرك) ونتائج اختباراتها |
| `test/` | الاختبارات (تعمل على النسختين الأصلية والمعدّلة) |
| `audit/` | سكربتات الفحص الأولى على النسخة الأصلية |

## التثبيت

1. في Tampermonkey: عطّل نسخة v3.3 أو احذفها (بياناتها المحفوظة لا تُمس، فـv3.4 يستخدم مفاتيح تخزين جديدة `wsnf33s_*`).
2. أنشئ سكربتًا جديدًا والصق محتوى `dist/wsnf.user.js` (إن كانت v3.5 مثبتة: استبدل محتواها؛ البيانات والمفاتيح نفسها).
3. افتح المنصة وحدّث الصفحة. يظهر شعار «🛡 محاكاة فقط».

## التشغيل والاختبارات (Node.js ≥ 18، بلا أي مكتبات خارجية)

```bash
npm run build            # src/ → dist/wsnf.user.js
npm test                 # التحقق من dist + كل اختبارات Node (98) بما فيها الذهبي مقابل v3.5 (~25 ث)
npm run test:original    # نفس الاختبارات على النسخة الأصلية (تفشل اختبارات السلامة والأخطاء عمدًا)
npm run test:stats       # اختبار ضابط إحصائي على حركة عشوائية (~2 د)
npm run compare:all      # جدول قبل/بعد لكل الاختبارات ← docs/TEST_RESULTS.md
npm run test:browser     # الواجهة + المسجّل على IndexedDB حقيقي + الواجهة لا تؤثر على المحرك (Chromium/Playwright)
npm run compare:c        # جدول v3.5 مقابل v3.6 ← docs/TEST_RESULTS_C.md
```

## مسجّل الشموع

صفحة «المسجّل» في الواجهة: حالة التسجيل، عدد الشموع لكل أصل وإطار، الفجوات، أسباب الرفض، الأحداث،
وتصدير/استيراد JSONL وCSV. البيانات في IndexedDB داخل متصفحك فقط (≈ 0.44 MB لكل يوم كامل على إطار دقيقة لأصل واحد).
