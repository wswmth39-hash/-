# POCKET OPTION SMART BOT — V1.0 قيد التطوير (المرحلة 2 من 7)

Userscript يحلل أسعار المنصة الفعلية لحظيًا ويعرض إشارات مفسَّرة ويسجّل نتائجها الفعلية.
**تحليل وإشارات فقط: لا ينفّذ صفقات، لا ينقر أي زر في المنصة، ولا يرسل أي أمر، ولا يستخدم رمز الجلسة.**
أداة مستقلة غير تابعة لـ Pocket Option.

> لا يوجد دليل على أن هذا النظام مربح، والإشارات ليست مضمونة. «قوة الإشارة» درجة توافق مؤشرات وليست احتمال نجاح.
> مصدر البيانات قراءة سلبية لاتصال صفحة المنصة، وهو غير موثّق رسميًا وصيغه لم تُتحقق بعد على الصفحة الحقيقية.

تقرير المرحلة الحالية وما لم يُبنَ بعد: `docs/V1_STAGE_2.md`. المشروع مبني على WSNF Smart Bot v4.0-dev (المستندات الأقدم أدناه ما زالت صالحة للمحرك).

## التثبيت

1. في Tampermonkey: عطّل نسخة v3.3 أو احذفها (بياناتها المحفوظة لا تُمس، فـv3.4 يستخدم مفاتيح تخزين جديدة `wsnf33s_*`).
2. أنشئ سكربتًا جديدًا والصق محتوى `dist/wsnf.user.js` (إن كانت v3.5 مثبتة: استبدل محتواها؛ البيانات والمفاتيح نفسها).
3. افتح المنصة وحدّث الصفحة. تظهر واجهة POCKET OPTION SMART BOT؛ الصفحات القديمة تحت «متقدم».

## التشغيل والاختبارات (Node.js ≥ 18، بلا أي مكتبات خارجية)

```bash
npm run build            # src/ → dist/wsnf.user.js
npm test                 # التحقق من dist + كل اختبارات Node (112) بما فيها الذهبي مقابل v3.5 (~30 ث)
npm run test:original    # نفس الاختبارات على النسخة الأصلية (تفشل اختبارات السلامة والأخطاء عمدًا)
npm run test:stats       # اختبار ضابط إحصائي على حركة عشوائية (~2 د)
npm run compare:all      # جدول قبل/بعد لكل الاختبارات ← docs/TEST_RESULTS.md
npm run test:browser     # Chromium: الواجهة الجديدة (كمبيوتر وجوال، عربي/إنجليزي)، الواجهة القديمة، المسجّل على IndexedDB حقيقي، الواجهة لا تؤثر على المحرك، الاستقبال عبر WebSocket حقيقي
npm run compare:c        # جدول v3.5 مقابل v3.6 ← docs/TEST_RESULTS_C.md
```

## مسجّل الشموع

صفحة «المسجّل» في الواجهة: حالة التسجيل، عدد الشموع لكل أصل وإطار، الفجوات، أسباب الرفض، الأحداث،
وتصدير/استيراد JSONL وCSV. البيانات في IndexedDB داخل متصفحك فقط (≈ 0.44 MB لكل يوم كامل على إطار دقيقة لأصل واحد).
