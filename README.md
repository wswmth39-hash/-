# WSNF Smart Bot — v3.4 (محاكاة فقط)

Userscript يحلل أسعار المنصة ويصدر إشارات وصفقات **افتراضية** فقط (Paper Trading).
**لا ينقر أي زر في المنصة، ولا يرسل أي أمر، ولا يقرأ المبلغ أو الرصيد.**

> لا يوجد دليل على أن هذا النظام مربح. على بيانات عشوائية يعطي نحو 50% كما يجب (لا تسرّب ولا عكس منهجي).
> الحكم على وجود أي أفضلية يحتاج بيانات حقيقية واختبارًا خارج العينة (المرحلتان D وE). انظر `docs/AUDIT_REPORT.md`.

## الملفات

| المسار | الوصف |
|---|---|
| `src/wsnf.user.js` | **النسخة المعدّلة (v3.4)** — هذا ما تثبّته |
| `original/wsnf_v3.3.user.js` | النسخة الأصلية كما استُلمت (نسخة احتياطية، لا تُعدَّل) |
| `docs/AUDIT_REPORT.md` | تقرير الفحص (المرحلة الأولى) |
| `docs/STAGE_AB.md` | ما تغيّر في المرحلتين A وB، ولماذا، وما الذي أُجّل |
| `docs/TEST_RESULTS.md` | جدول الاختبارات قبل/بعد (يُولَّد آليًا) |
| `docs/RECORDER_DESIGN.md` | تصميم مسجّل الشموع (للمرحلة D) |
| `test/` | الاختبارات (تعمل على النسختين الأصلية والمعدّلة) |
| `audit/` | سكربتات الفحص الأولى على النسخة الأصلية |

## التثبيت

1. في Tampermonkey: عطّل نسخة v3.3 أو احذفها (بياناتها المحفوظة لا تُمس، فـv3.4 يستخدم مفاتيح تخزين جديدة `wsnf33s_*`).
2. أنشئ سكربتًا جديدًا والصق محتوى `src/wsnf.user.js`.
3. افتح المنصة وحدّث الصفحة. يظهر شعار «🛡 محاكاة فقط».

## التشغيل والاختبارات (Node.js ≥ 18، بلا أي مكتبات خارجية)

```bash
npm test                 # اختبارات السلامة والأخطاء والانحدار على النسخة المعدّلة (~30 ث)
npm run test:original    # نفس الاختبارات على النسخة الأصلية (تفشل اختبارات السلامة والأخطاء عمدًا)
npm run test:stats       # اختبار ضابط إحصائي على حركة عشوائية (~2 د)
npm run compare:all      # جدول قبل/بعد لكل الاختبارات ← docs/TEST_RESULTS.md
node test/ui.smoke.js docs/ui_v3.4.png   # اختبار الواجهة في Chromium (يتطلب Playwright)
```
