# WSNF SMART BOT — الفحص التقني والخطة الرئيسية للترقية الشاملة

نقطة البداية: **v3.6**. نسختها الاحتياطية في `backup/wsnf_v3.6.user.js` (مطابقة بالـhash لـ`dist/wsnf.user.js`).
النسخ الأقدم: `backup/wsnf_v3.5.user.js` و`original/wsnf_v3.3.user.js`.

## أولًا: حدود يجب أن تُعرف قبل أي شيء (بصراحة)

1. **لا أستطيع فتح صفحة Pocket Option الحقيقية من بيئة العمل هذه.**
   * شبكة البيئة تحجب `pocketoption.com` و`po.market` (البروكسي يرد 403، مُثبت).
   * حتى لو لم تكن محجوبة، فالبث الحي للأسعار يتطلب جلسة مسجّلة الدخول، ولن أسجّل الدخول إلى حسابك ولن أطلب بياناته.
   * **النتيجة:** صيغ رسائل المنصة الحقيقية لم يرها أحد منا داخل هذا المشروع. الكود الحالي يقرأ `updateStream` و`updateHistoryNew*`، وهما موروثتان من الإصدار الأصلي ولم يُتحقق منهما.
   * **الحل الصادق (المرحلة 3):** أداة «استكشاف بيانات المنصة» داخل البوت. تشغّلها أنت على صفحتك الحقيقية، فتسجّل أسماء الرسائل وبنيتها فقط دون أي بيانات حساب. تصدّر تقريرها وترسله لي، وعليه أبني القراءة على الصيغ الحقيقية بدل التخمين.
2. **لا أستطيع إرسال رسالة Telegram حقيقية من هنا.** الشبكة تحجب `api.telegram.org` (403)، والإرسال يحتاج مفتاح البوت الخاص بك.
   أختبر العميل على خادم Bot API مُحاكى، وأوفر زر «رسالة اختبار» وسكربت تحقق تشغّلهما أنت.
3. **لا أستطيع تشغيل Tampermonkey هنا.** أختبر الملف في Chromium حقيقي عبر Playwright، بنفس طريقة الحقن ومع محاكاة خادم WebSocket داخل المتصفح.
   التحقق النهائي داخل Tampermonkey على صفحتك يجب أن تقوم به أنت (قائمة تحقق في تعليمات التشغيل).
4. **إعادة الاتصال تقوم بها المنصة نفسها.** البوت لا يفتح اتصالًا خاصًا بالمنصة، لأن ذلك يتطلب إرسال بيانات جلستك. دوره:
   * يرصد الانقطاع.
   * يوقف التحليل ويلغي الصفقة الافتراضية المفتوحة.
   * يستأنف بأمان عند عودة البيانات، ويعلّم الفجوة.
   * ينبّهك إن لم تُعِد المنصة الاتصال (اقتراح إعادة تحميل الصفحة).
5. **«إثبات أن مؤشرًا يضيف قيمة» يحتاج بيانات حقيقية كافية.** على البيانات المصطنعة يمكن إثبات أن الفلتر لا يسرّب المستقبل ولا يضر، لا أنه يربح.
   لذلك تُبنى الاستراتيجيات والفلاتر الجديدة **معطلة عن القرار** حتى يثبت الـBacktesting خارج العينة قيمتها على بياناتك المسجّلة، وبموافقتك.

## ثانيًا: الوضع الحالي لكل متطلب

الرموز: ✅ موجود ومختبر · 🟡 موجود جزئيًا · ❌ غير موجود · 🔒 يحتاج تحققًا منك على الصفحة الحقيقية

| المتطلب | الوضع | التفاصيل |
|---|---|---|
| واجهة عربية RTL | ✅ | كل الواجهة والتقارير والسجل بالعربية. اختبار في Chromium يثبت تطابق نص الصفحات بين الإصدارات |
| نسخة احتياطية | ✅ | v3.3 وv3.5 وv3.6 محفوظة |
| قراءة بيانات المنصة الحقيقية | 🟡🔒 | اعتراض WebSocket للقراءة فقط. **الصيغ غير متحقق منها على المنصة** |
| حالة مستقلة لكل اتصال (`expect`) | ❌ | خلل مؤكد في `src/platform/ws.js`: `expect`/`expectWs` مشتركة بين كل الاتصالات |
| مرفقات ثنائية متعددة (`45N-`) | ❌ | يُعالج مرفق واحد فقط |
| تسجيل أخطاء التحليل بدل تجاهلها | 🟡 | أخطاء الإطار الثنائي تُسجَّل؛ **أخطاء JSON في الرسائل النصية تُبتلع بصمت** (`catch (e) {}`) |
| التحقق من صحة التيك | 🟡 | أنواع القيم فقط، ورفض التيك الأقدم من الشمعة. **لا كشف للتكرار ولا للقفزة الشاذة ولا للوقت غير المنطقي** |
| حالة البيانات (LIVE/متأخر/قديم/غير متاح) | 🟡 | «بيانات قديمة» بعد 8 ث فقط. **لا آلة حالات، والاتصال المفتوح بلا بيانات لا يُميَّز عن الحي** |
| كشف تغيير الأصل | 🟡 | الأصل الحالي = آخر أصل وصل له تيك؛ يُقارن باسم الأصل المعروض للعرض فقط. لا حدث «تغيّر الأصل» |
| بناء الشموع من التيك | ✅ | مختبر مقابل مرجع مستقل (D1) |
| مقارنة الشموع المبنية بشموع المنصة | ❌🔒 | لا نعرف إن كانت المنصة ترسل شموعًا جاهزة (يكشفها تقرير الاستكشاف) |
| حفظ البيانات بعد إعادة التحميل | 🟡 | الشموع والإحصاءات محفوظة (مختبر في Chromium). **نافذة التحليل لا تُستعاد من الشموع المحفوظة** |
| منع المستمعين المكررين | ❌ | إن حُقن السكربت مرتين يُلَف WebSocket مرتين. لا حارس |
| تسرّب الذاكرة | 🟡 | الحدود موجودة للسجلات، لكن `S.candles` يحتفظ بـ5000 شمعة **لكل أصل فُتح**، بلا حد لعدد الأصول |
| المؤشرات صحيحة رياضيًا | 🟡 | RSI مختبر مقابل مرجع. **EMA وSMA وATR وMACD وبولينجر وستوكاستك بلا اختبار مرجعي.** ATR متوسط بسيط وليس Wilder |
| تحليل السوق (اتجاه، نطاق، اختراق، وهمي، انعكاس، انضغاط، تقلب، أطر متعددة) | ✅ | `src/core/context.js` + الفلاتر |
| كشف الشذوذ | 🟡 | قفزة سعرية وقفزات شاذة في جودة البيانات |
| رفض الإشارات المتعارضة | ✅ | أصوات معاكسة ≥ 30%، واتفاق العناقيد، والإطار الأعلى |
| قرار «لا تداول» | ✅ | الامتناع هو الأصل، مع سبب مسجّل |
| شرح عربي لكل إشارة | 🟡 | الأسباب محفوظة. **لا فصل منظم بين المؤكِّد والمعارض والمخاطر** |
| معايرة الثقة | 🟡 | فاصل ثقة 95% للنتائج الحية والبوابة. **«القوة» ليست احتمالًا** ومذكورة كذلك |
| استراتيجيات متعددة مستقلة بإعدادات | 🟡 | 17 «مصوّتًا» يتحدون في قرار واحد. **لا «استراتيجيات» مستقلة بإعدادات وتشغيل/إيقاف وإحصاء خاص** |
| التعلّم والإحصاء | 🟡 | لكل مصوّت × أصل × حالة سوق، وكشف تدهور. **لا تقسيم تدريب/اختبار زمني ولا Walk-forward ولا تصحيح للمقارنات المتعددة** |
| موافقة المستخدم قبل أي تغيير | 🟡 | التجارب تحتاج زر «اعتمد». **تبديل النسخ المعدّلة تلقائي** (بعد z ≥ 2.3 و100 عينة) — يجب أن يصبح بموافقة |
| إدارة المخاطر | 🟡 | خسائر متتالية + استراحة، وحد خسارة، وحد بالساعة، وتهدئة، ومنع التكرار، وحماية من البيانات القديمة. **لا حد يومي ولا حد للجلسة ولا مبلغ افتراضي قابل للضبط.** لا مضاعفة (Martingale) أصلًا ✅ |
| Paper Trading على الأسعار التالية الحقيقية | ✅ | الدخول عند أول تيك بعد الإشارة، والتسوية من تيك الانتهاء. **الصافي يُحسب بالعائد العام لا بعائد الأصل** (خلل موثّق) |
| Backtesting | ❌ | المرحلة المؤجلة |
| Telegram | ❌ | — |
| Python | ❌ | — |
| CSV مع علامات الاقتباس | ❌ | `split(',')` |
| لوحة السوق الحي والشارت | 🟡 | شارت لآخر 90 شمعة مع EMA. لا شارت تيك، ولا اختيار أصل، ولا تفاصيل الشمعة الحالية |
| لوحة صحة النظام | 🟡 | سجل الأخطاء والمسجّل. لا حالة WebSocket تفصيلية ولا Python ولا Telegram |

## رابعًا: قرار تقني مطلوب لاحقًا (المرحلة 10)

**أين يُحفظ مفتاح Telegram:**

| الخيار | المزايا | العيوب |
|---|---|---|
| **التوصية: تخزين Tampermonkey المحمي** (`GM_setValue`) + الإرسال عبر `GM_xmlhttpRequest` | لا تستطيع سكربتات المنصة قراءة المفتاح، ولا يحجب CSP الصفحة الإرسال | يتطلب `@grant`، فيعمل السكربت معزولًا ويصل إلى WebSocket الصفحة عبر `unsafeWindow`. قد يتأخر الحقن في بعض الإعدادات فيفوته أول اتصال، وسأكشف ذلك وأعرضه |
| البديل: `localStorage` + `fetch` | أبسط | المفتاح يصبح مقروءًا لسكربتات المنصة، وقد يحجب CSP الإرسال |
